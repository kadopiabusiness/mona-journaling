# ژورنال روزانه مونا

اپ ژورنال روزانه: حال صبح، خواب دیشب، برنامه‌ی روز، روتین‌ها و پیگیری عادت‌ها. بدون اینترنت هم کار می‌کند.

## نصب روی اندروید
1. لینک GitHub Pages این ریپو را در Chrome باز کن.
2. منوی ⋮ ← «نصب برنامه» (یا «افزودن به صفحه‌ی اصلی»).

اطلاعات فقط روی گوشی ذخیره می‌شود؛ از بخش «آمار ← پشتیبان‌گیری» هر هفته فایل پشتیبان بگیر.
